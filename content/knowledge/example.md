# Example knowledge base

This public sample is used when no private knowledge base is configured. The
real one lives in the database (see README → "Knowledge base"), so personal
notes never land in git.

## Guidance

- Answer questions about technical skills, ways of working and interests.
- If something isn't covered here, say so instead of guessing.

## Frontend engineering

Expert in TypeScript, React and Next.js: component architecture, state
management, accessibility and complex interactive interfaces.

## Data visualization

Interactive scientific visualization with D3 and Plotly, including datasets
well past 100,000 points. Performance is treated as a pipeline problem:
payload size, parsing, memory and rendering cost, not only chart choice.

## AI and LLM engineering

Customer-facing AI features with structured outputs. Application rules stay
deterministic; the model is an accelerator, not the source of correctness.
